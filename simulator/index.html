fictional plant

In simulated mode, this is a deliberately fictional plant: higher setting numbers make the simulated shot faster. That direction is not a DF64 conversion. Pressure and flow are recorded as context; GBS itself only receives the documented timing inputs.

The “Brew” button runs the current recommendation through the fictional plant. “Run planned shots” uses the table below one row at a time and can always be replayed from reset.

How to read this

The algorithm gets a brew time, target time, current setting, and tolerance. It returns a candidate and a returned setting. A hold or cancel means it is deliberately waiting for better evidence.

Plain-language guide

GbS1 smooths recent results. GbS2 fits a line. GbS3 keeps a cautious middle phase. GbS4 locks near the target. DdEff deliberately sweeps settings so a later measurement can learn the grinder.
